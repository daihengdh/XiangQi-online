# 象棋对战（网页版）

一个零依赖的网页版中国象棋对战平台：**人机对战（五档难度）** + **局域网联机对战** + **残局闯关（十大杀法关卡）** + **线下对战辅助（最强 AI 支招）** + **战绩统计（按昵称区分用户）** + **JJ象棋风格的分类绝杀特效**。

参考了微信小程序「JJ象棋」的演出风格：将军大字横幅、吃子斩击火花、**按杀法分类的绝杀演出**（重炮！！/ 马后炮！！/ 双车错！！/ 卧槽马！！等 11 类，各有专属大字、配色与动画节奏）、拟物木纹棋盘与立体棋子、程序化音效（落子/吃子/将军锣/绝杀重鼓，无需任何音频素材）。

## 线下对战辅助

和朋友面对面下**实体棋盘**时的随身军师：

1. 大厅进入「♟ 线下对战」，选择自己执红（先行）或执黑（后行）
2. 屏幕棋盘是实体棋盘的镜像——**对手走一步，你点一下**：先点他的棋子（起点），再点落点，这步棋就录入了
3. 轮到你时，**最强 AI 自动开算**（大师档深度 20、5 秒预算、启用开局库）：棋盘上画出金色流动箭头，面板大字显示建议着法与局势解读
4. 你照建议走子后，点击同样的「起点 → 落点」完成记录；想走自己的选择也行，点击实际着法即可，AI 下一回合继续支招

- 点错一步随时「悔棋」（单步撤销，撤销后自动重新支招）
- 将军 / 吃子音效、按杀法分类的绝杀演出全部保留；将死弹结算面板（再来一局 / 返回大厅）
- 局面异常可「悔棋」回退逐步核对；支持中局换边重开
- 线下对局不计入战绩统计

## 战绩统计

- **按昵称区分用户**：大厅改昵称即切换战绩档案（localStorage 持久化）
- 三个维度分开统计：**人机**（含各 AI 档位胜负明细）、**联机**（胜/负/和）、**残局**（通过关数 + 挑战成功率）
- 大厅实时显示战绩面板；胜利后的结算面板提供"再来一局/重试本关/下一关/返回大厅"按钮（联机再来一局为双方确认并自动换先手）

## 快速开始

### 家里/本机自己玩（人机、残局）

把整个项目文件夹拷到任意电脑，双击 `start.bat`，浏览器打开打印出的本机地址即可。**零网络依赖**——人机对战、残局闯关、全部特效不需要任何网络。

### 外网对战（家里 ↔ 公司，内网穿透）

想让家人/朋友在别的网络和你联机？双击 **`start-public.bat`**（或 `node tunnel.js 8080`）：

1. 首次运行会自动下载穿透工具 cloudflared（约 50MB，公司网络下不好下就换手机热点试一次，之后就不用了）
2. 稍等十几秒，窗口会打出一个 **https://xxxx.trycloudflare.com** 的公网地址
3. 把这个地址发给对方——对方在任何网络（家里 WiFi、手机流量）的浏览器打开，走「局域网联机」房间码流程照常对战

说明：
- 免费无需注册，WebSocket 联机/聊天/计时全部正常（已实测 wss 握手 + 公网建房）
- 地址是**临时的**：重启脚本后地址会变，重新发一次即可
- 对外服务期间保持 `start-public.bat` 窗口开着；关掉窗口即停止对外服务
- 公司 WiFi 内的同事仍可直接用局域网地址访问，不受影响

### 启动服务器（一台机器即可）

双击 `start.bat`，或在项目目录运行：

```
node server.js          # 默认 8080 端口
node server.js 9000     # 自定义端口
```

启动后控制台会打印本机和局域网地址，例如：

```
本机：  http://localhost:8080
局域网：http://192.168.8.13:8080  ← 同事在浏览器打开即可
```

- **自己玩人机**：本机浏览器打开即可，不需要联机。
- **同事联机**：同一局域网内的任何设备（电脑/手机浏览器）打开局域网地址。

## 人机对战 · 五档难度

| 档位 | 说明 |
|---|---|
| 入门 | 深度 1 + 大噪声随机，随手走子，适合完全新手 |
| 初级 | 深度 2 + 噪声，会主动吃子送子，偶尔失误 |
| 中级 | 深度 3，有战术意识，注意子力安全 |
| 高级 | 深度 4，稳健老练，抓得住漏着 |
| 大师 | 迭代加深至深度 12（2.6 秒限时），全力搜索 |

引擎：negamax + alpha-beta 剪枝 + 迭代加深 + 置换表 + 杀手/历史启发 + 静态搜索 + 将军延伸 + 开局库随机化。对局中可随时切难度或换边。

## 局域网联机功能

- 服务器权威制：所有着法在服务器端用规则引擎校验，客户端无法作弊
- 每方 15 分钟包干 + 每步加 30 秒
- 求和 / 悔棋（双方确认）/ 认输 / 聊天
- **结算面板：再来一局（双方确认、自动换先手）/ 返回大厅**
- 掉线 60 秒宽限内可重连；页面刷新自动恢复对局
- 超时 / 认输 / 将死 / 困毙 / 六十回合无吃子 / 双方掉线 等结束方式全部支持

## 第三方引擎（engines/）

下载的知名开源象棋引擎，供对比与接入：

| 目录 | 引擎 | 说明 | 许可 |
|---|---|---|---|
| `engines/pikafish/` | **Pikafish（皮卡鱼）** | 目前最强开源象棋引擎（NNUE 神经网络，Stockfish 同源），含 Windows exe + NNUE 权重（已随仓库分发，克隆即用），UCI 协议 | GPL-3.0 |
| `engines/xqwlight/` | **XQWLight（象棋巫师轻量版）** | 纯 JavaScript 引擎（2012），可直接跑在浏览器里，自带开局库 | GPL-2.0 |

来源：Pikafish 官方 release（github.com/official-pikafish/Pikafish）；exe+NNUE 文件取自 liutq25/ChineseChess 仓库（省去官方 7z 分发）。xqwlight 来自 xqbase/xqwlight。

**皮卡鱼已接入**（2026-09-19）：服务器启动时自动加载 `engines/pikafish/`（NNUE 权重），提供 `POST /api/bestmove {fen, movetime?}` 接口；**线下对战辅助模式**的支招与**人机对战/残局闯关的 💡支招按钮**均优先走皮卡鱼（深度 30+），服务器未开或引擎缺失时自动回退内置大师档 Worker，输出会标注来源（【皮卡鱼 NNUE】/【内置】）。人机对战的 AI 对手仍为内置引擎。桥接模块：`tools/pikafish-uci.js`。

**线下模式自动替走 + 复盘分析**（2026-09-19）：线下面板新增「🤖 皮卡鱼自动替我走子」开关——开启时只需录入对手着法，皮卡鱼算完直接在页面替你走棋（照着实体落子即可）；关闭则回到建议+手动录入。侧栏可随时点「📊 复盘分析」或对局结束后从结算面板进入复盘：皮卡鱼逐着对比，JJ 风格标注好棋/失误/大漏招/败着（含每步损失分与更好走法），并生成风格画像（攻守倾向/子力偏好/走偏率），支持一键复制战报。

## 技术说明

- **零依赖**：不需要 npm install，只用 Node.js 内置模块；WebSocket 为 RFC6455 手写实现
- **规则完整**：蹩马腿、塞象眼、士不出宫、象不过河、炮隔子吃、兵过河横走、白脸将（将帅照面）、送将过滤、困毙判负、60 回合无吃子和棋、三次重复局面按和棋处理
- **防作弊**：联机对局每步都经服务器规则校验，非法着法直接拒绝并回滚客户端乐观更新
- **IE 不支持**：现代浏览器（Chrome/Edge/Firefox/Safari）均可
